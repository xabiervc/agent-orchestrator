# agent-orchestrator v0.1.0

Initial provider-agnostic orchestration core for coding agents.

## Included

- Project initialization with reusable profiles.
- Run and artifact lifecycle.
- Haiku, Sonnet, Opus, and manual extended-routing policy.
- Claude Code, Codex, and Copilot command plans.
- Provider availability detection through PATH.
- Prompt generation.
- Strict artifact validation.
- Deterministic consensus gate.
- Worktree planning.
- Optional 3D asset server plugin.
- License and provenance tracking.
- ZIP traversal protection.
- Offline test suite.
- GitHub Actions CI.

## Supported profiles

- Generic software.
- Godot.
- Unreal.
- Unity.
- Mobile.
- Web.
- Desktop.
- Backend.
- Asset pipeline.

## Important limitations

- Provider commands are planned but not executed automatically.
- Credentials are never managed by the core.
- Asset-server network transports are not included by default.
- The public API may change before v1.0.0.
